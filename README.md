# 舌战

女性向双人卡牌对话游戏。V7 默认进入 H02「陆星河 × 程严」的 BeReal 咖啡厅交锋，按最新已保存剧本呈现对话、阈值回应与胜／负／平局后内容；原三套演示仍可从右上角切换。界面延续用户确认的烟紫、玫瑰色半透明恋爱风格与十回合规则。

这是独立的静态游戏适配，使用立绘、旁白和逐句文字呈现剧本内容。剧本中标为“局后影片”的段落目前也是文字与立绘，尚无原始影片片段或录制配音；页面音效由本地代码合成。

## H02 来源与对话流程

H02 的来源版本为 `edf045ff-12d3-4c71-8020-88aa78204d89`；`dist/assets/h02-story.js` 记录来源指纹 `imported-project-manuscript-v1:sha256:d88beec543d8dfc461327a779730dbbe65f7bef3bcd6d4165bf57c1b8c19e99a`，并集中保存卡牌台词、阈值完整问答与听方反应、三种局后内容和共同离场队列。当前场景是咖啡厅：陆星河持外带杯站在左侧，程严穿扣好的正装坐在右侧，左手藏于桌下。

开场对白、阈值对白和局后对白都需要玩家点击“继续对话”等推进按钮逐句阅读。对白队列清除倒计时并锁定手牌，读完后才恢复出牌，重新获得 10 秒回应时间；旁白或听方反应也占独立一步。重开或切换故事会取消旧局的回调，旧队列不能恢复新局。

| 首次跨越的正向交锋值 | 阈值组 | 女主自然表演状态 |
| --- | --- | --- |
| +1 | 职业称呼 | idle：从容直视 |
| +3 | 昨夜反差 | playful：玩味调侃 |
| +5 | 争到回应 | intent：探究笃定 |

每组完整问答与反应在一局内只播放一次。单次碾压跨过多个尚未播放的阈值时，按 +1、+3、+5 的升序排队；回退后再跨越不会重播。阈值组不代替数值判定，也不改变牌局平衡。

程严的立绘按以下数值优先级选择：交锋达到 +8 时为 `defeated`；否则心率达到 75% 时为 `overload`；否则本轮存在移开视线状态或交锋至少为 +2 时为 `flustered`；其余为 `idle`。女主的三种自然表演状态由阈值段落指定，不能用剧情语气覆盖男主的数值情绪。例如负局若心率仍为 82%，程严仍显示 `overload`，不会因为输赢标题被强制改成平静或破防立绘。

结算先显示真实回合与交锋值，玩家点击“继续剧情”后，按胜／负／平读取对应局后队列，再统一接共同离场：程严离开、助理留下接待。离场以旁白和立绘隐去呈现。读完后再显示结束面板，可重玩或换幕。胜局只表现争到一次正面回应，不扩大成臣服、坦白或额外惩罚。

## 操作与十回合规则

点击四张手牌之一，也可聚焦后按 Enter 出牌。可出牌阶段每轮思考时间为 10 秒，超时自动出牌。

- 直球克掩饰，掩饰克试探，试探克直球；同属性比较点数。
- 普通胜出推进 1；仅有克制或仅有大点差，仍推进 1。
- 只有属性克制成立，且胜方点数至少领先 4 点，才触发碾压，推进 3。
- 深情凝视抵消本轮攻势、心率增加 22%，不推进交锋值；反客为主无视属性克制，稳定推进 1。特殊牌不触发碾压。
- 交锋值从 0 开始，达到 +8 为我方击破，达到 −8 为对方击破；没有碾压时，最早第 8 轮击破。
- 最多 10 回合。第 10 回合结束时未击破，按交锋值正负判胜负；为 0 则平局。心率是游戏百分比状态，不能解释为医学 BPM。

克制图例常驻手牌上方，箭头指向被克制属性；指向或聚焦普通手牌时，对应关系高亮。判定与阈值阅读阶段保留刚完成的回合编号，下一轮开放手牌时再更新。卡牌点数、属性、效果和对话均为实时 HTML。
