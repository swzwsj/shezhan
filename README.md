# 舌战

双人卡牌对峙游戏，基于用户提供的 `code_artifact.html`。当前版本按用户最新纠正：粉色人物（原图1）为左侧女主／玩家，西装人物（原图2）为右侧男主／对手。三套剧本和全部情绪状态使用同一正确映射；两张人物 PNG 保留原文件字节与透明背景。

## 项目位置与隔离

独立源码位于 `C:/Users/szxcz/Documents/ChatGPT/xinfang/舌战`，有自己的 Git 仓库、依赖和 `.openai/hosting.json`。父目录 `xinfang` 的三消应用不引用本游戏；父仓库通过本地 Git exclude 排除此子目录。本游戏不是影游剧本平台的生产代码。

## 本地玩

直接用浏览器打开 `dist/index.html`，或在本目录运行 `node preview.mjs`，访问终端显示的 Local 地址。页面不需要服务端或模型 API；断网时外部字体回退到系统字体，人物、背景、样式和逻辑均在本地。

## 操作与十回合规则

点击底部四张手牌之一，也可聚焦后按 Enter 出牌。每轮思考时间为10秒，超时自动出牌。

- 直球克掩饰，掩饰克试探，试探克直球；同属性比较点数。
- 普通胜出推进1；仅有克制或仅有大点差，仍推进1。
- 只有属性克制成立，且胜方点数至少领先4点，才触发碾压，推进3。
- 深情凝视抵消本轮攻势、心率增加22%，不推进交锋值；反客为主无视属性克制，稳定推进1。特殊牌不能绕过碾压条件造成大量伤害。
- 交锋值从0开始，达到+8为我方击破，达到−8为对方击破；没有碾压时，最早第8轮击破。
- 最多10回合。第10回合结束时未击破，按交锋值正负判胜负；交锋值为0则平局。结局后可重玩或切换剧本。

`dist/assets/duel-rules.js` 是实际游戏与验证脚本共用的判定模块。统计验证包含固定种子的三种出牌策略，各10,000局；它是规则节奏证据，不代替真人试玩。

## 人物、场景与界面

V5按用户确认的“恋爱沉浸优先”重做界面：花瓣粉、暖白与雾紫文字，顶部中央为回合—心率双联大UI，中下部为浮动姓名签与信笺式对话框。心率继续使用游戏原有百分比状态值。克制图例常驻手牌上方，箭头指向被克制属性；聚焦或指向普通手牌时，对应关系高亮。判定期间显示当前交锋回合，下一轮开放手牌时再切换回合，到达结局明确显示本幕结束。

字体使用自托管站酷小薇体，来源与OFL许可位于 dist/assets/fonts/，不再调用外部字体样式服务。产品约束见 PRODUCT.md，实施后的视觉规范见 DESIGN.md。开发设计记录不进入静态发布目录。

女主使用 `dist/assets/character-pink.png`，男主使用 `dist/assets/character-suit.png`。双方按左近右远的站位放大，保持人物原比例；宽幅横向对话区承载完整台词。三套剧本分别对应深夜书房、假面舞会回廊、月下竹影寒潭，背景位于 `dist/assets/backgrounds/`。

牌面使用素色底、单边框、大点数和短效果文字；完整台词在出牌时进入横向对话区，并保留于辅助说明。旧插画文件保留在 `dist/assets/cards/` 作为历史素材，当前牌面不加载这些图片。

判定采用透明底描边大字，分别展示点数、克制、碾压、特殊牌和平局的真实结果与伤害，碾压才触发强烈镜头震动。动画尊重系统减少动态效果的偏好。样式分别在 `stage.css`、`cards.css`、`duel-ui.css`，无跨项目代码依赖。

右上角可切换剧本、开关音效、调整场景／立绘及 JSON 配置；这些编辑仅对当前页面会话生效，刷新后恢复已部署默认配置。规则无效时显示错误并保留编辑文本。

## 修改、验证与构建

主页面为 `dist/index.html`。Tailwind CSS 在构建时生成，运行页面无需 Tailwind CDN。

```powershell
npm ci
npm run check
npm run build
node preview.mjs
```

静态发布目录为 `dist`。后续更新继续复用 `.openai/hosting.json` 的站点身份与当前访问范围。打包归档应输出到项目目录以外，避免将归档包含进自身。
